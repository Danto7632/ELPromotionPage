## 📌 프로젝트 소개

**EL 동아리 홍보 페이지는 신입생들에게 동아리를 소개하기 위한 웹사이트입니다.**  
동아리 활동 안내, DevTI 성격유형검사 연동, 프로젝트 포트폴리오 등을 통해  
동아리의 매력을 효과적으로 전달하는 것이 목표입니다.

- 🎯 React 기반 SPA로 부드러운 사용자 경험
- 🎨 DevTI 카드 인터랙션 및 애니메이션 효과
- 📱 완전 반응형 디자인
- 🔗 YouTube, GitHub 외부 서비스 연동

---

## 🔍 주요 기능

- **동아리 소개 및 성과**
  - PD Lab Pre-Star 선정 동아리 소개
  - 2023년 7가지 주요 실적 강조

- **DevTI 성격유형검사 연동**
  - 16가지 개발자 성격유형 카드 그리드
  - 호버 애니메이션 및 외부 사이트 연결

- **동아리 활동 소개**
  - 행사, 튜터링, 프로젝트 카테고리별 분류
  - 각 활동별 이미지 갤러리 및 상세 설명

- **프로젝트 포트폴리오**
  - EXPO 프로젝트, 동계 프로젝트 등 주요 성과물
  - YouTube 시연 영상 및 GitHub 링크 연동

- **반응형 웹 디자인**
  - Framer Motion 스크롤 애니메이션
  - 모든 디바이스 대응

---

## 🎨 기타 디자인 포인트

- **Pretendard 폰트 적용**  
  일관된 타이포그래피로 가독성 향상

- **인터랙티브 애니메이션**  
  Animate.css와 Framer Motion으로 풍부한 사용자 경험

- **Mixpanel 분석 연동**  
  사용자 행동 데이터 수집으로 홍보 효과 측정
